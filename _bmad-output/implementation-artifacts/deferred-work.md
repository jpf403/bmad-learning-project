## Deferred from: code review of story-3.3-admin-edits-an-account, round 2 (2026-08-13)

- The admin-edit popup's Tab-trap has nothing to wrap during the brief `isSubmitting` window: every focusable control is disabled via the native `disabled` attribute while a save is in flight, so the trap's focusable-elements query returns empty, the browser blurs the disabled (formerly-focused) element to `document.body`, and a Tab press in that narrow window can escape into the page behind the modal.
